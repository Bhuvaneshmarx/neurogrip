02 / Signal chain

From skin to servo in 118 milliseconds

Three surface electrodes per channel sit over the forearm muscle bellies. What reaches the ESP32 is a few hundred microvolts of noise; everything after that is conditioning, measuring and deciding.

WHY SURFACE EMG

No surgery, no needles

Skin electrodes read the summed firing of motor units a few millimetres below. It is a blunt instrument compared to a nerve cuff, but it is safe, reversible and good enough to separate seven intents.

Electrode spacing20 mm
THE HARD PART

Electrode shift ruins models

Move a pad 10 mm and the feature distribution moves with it. The cuff keeps pads in a printed jig, and the model is trained on four re-donning sessions so it sees that drift during training rather than in the viva.

Accuracy drop, shifted pads−6.1 pt
SAFETY

Nothing mains-powered touches skin

The whole arm runs from a 2S LiPo. The analog stage is isolated from the servo rail by a separate buck converter and a common-mode reference, so servo inrush does not show up as a false grip command.

Servo rail6.0 V / 3 A
03 / On-device AI

A classifier small enough to live in flash

No cloud, no phone, no Raspberry Pi. The whole decision runs inside the ESP32 so the hand still works when the Wi-Fi does not.

Step 1 · Features, not raw samples

Feeding 200 raw samples to a network wastes flash. Instead each 200 ms window is reduced to the Hudgins set — five numbers per channel that survive amplitude drift:

FeatureWhat it capturesCost
MAVHow hard the muscle is working200 add
RMSEnergy, less sensitive to spikes200 mac
ZCRough frequency content199 cmp
WLSignal complexity199 abs
SSCSlope reversals, fatigue marker198 cmp

5 features × 2 channels = a 10-value input vector, computed in 0.4 ms.

Step 2 · The network

A three-layer perceptron, quantised to int8 and deployed with TensorFlow Lite for Microcontrollers. Deliberately boring: it fits, it is fast, and it is explainable in a viva.

Step 3 · Don't trust one frame

A single window flickers between classes at grip onset. The firmware takes a majority vote over the last three decisions before it moves a servo, which costs 14 ms and removes almost all twitching. Below an activation floor of 18% on both channels it stops classifying altogether and holds the rest posture, so baseline noise can never be read as a grip.

Pinch and tripod share almost the same flexor pattern, so they are the two classes that trade places. The fix is a third electrode channel over the thumb's abductor pollicis brevis, which is Phase 2 work rather than a modelling trick.

04 / Hardware

Every part is something you can buy in Chennai

The constraint was a working arm for under ten thousand rupees, printable on a 220 mm bed, with no part that takes six weeks to import.

COMPUTE

ESP32-WROOM-32

Dual-core 240 MHz Xtensa LX6. One core runs the sampling ISR and feature maths, the other runs inference and the servo scheduler, so sampling never jitters.

  • 520 KB SRAM, 4 MB flash
  • 2 × 12-bit SAR ADC
  • BLE for logging to a laptop
₹ 420Core 0 / Core 1 split
SENSING

2 × EMG front end

INA333 instrumentation amp, gain of 1000, with a 20–450 Hz band-pass and a 50 Hz notch for mains hum. Built on perfboard rather than bought, because the module price is five times the parts.

  • Ag/AgCl pads, 20 mm spacing
  • Driven reference on the elbow
  • Output biased to 1.65 V
₹ 1,1802 channels
ACTUATION

6 × MG996R servo

Metal-gear hobby servos in the forearm, each pulling a Dyneema tendon through a PTFE sleeve. Five for the fingers, one for thumb opposition.

  • 9.4 kg·cm stall at 6 V
  • Tendon return by silicone cord
  • Driven via PCA9685 I²C
₹ 2,3406 DOF
STRUCTURE

Printed PLA+ hand

Palm and phalanges printed at 0.16 mm with 40% infill; joints are 2 mm steel pins in printed bosses. Fingertips are TPU for grip and a bit of compliance.

  • 11 articulating joints
  • TPU pads, 95A shore
  • Printed electrode jig in the cuff
₹ 760420 g assembled
FEEDBACK

FSR fingertips + buzzer

A force-sensitive resistor under each TPU pad closes the loop: squeeze harder and a coin vibration motor on the upper arm buzzes faster, so the wearer feels grip without looking.

  • FSR-402, 0–20 N usable
  • Haptic 10–55 Hz mapping
  • Stops servo at force target

1500 mAh pack with two buck converters: a quiet 3.3 V for the analog stage and a 6 V 3 A rail for the servos, so motor inrush cannot be read as a muscle twitch.

05 / Firmware

The loop that does the work

Sampling lives in a hardware timer so the window length is exact. Classification and servo motion live on the other core. This is the core of neurogrip.ino, trimmed of logging.

Sampling ISR · core 0
// 1 kHz timer ISR. Keep it short: read, store, leave.
void IRAM_ATTR onSampleTimer() {
  static uint16_t idx = 0;
  ring[0][idx] = adc1_get_raw(CH1_FLEXOR);
  ring[1][idx] = adc1_get_raw(CH2_EXTENSOR);
  idx = (idx + 1) % WIN;              // WIN = 200 samples = 200 ms
  if (idx % HOP == 0) xSemaphoreGiveFromISR(windowReady, NULL);
}
Feature extraction · Hudgins set
void extractFeatures(const uint16_t* x, float* out) {
  float mav = 0, sq = 0, wl = 0;
  int   zc  = 0, ssc = 0;
  for (int i = 1; i < WIN; i++) {
    float v = (x[i] - BIAS) * LSB_MV;      // centre and scale to mV
    float p = (x[i-1] - BIAS) * LSB_MV;
    mav += fabsf(v);
    sq  += v * v;
    wl  += fabsf(v - p);
    if (v * p < 0 && fabsf(v - p) > ZC_EPS) zc++;
    if (i > 1 && slopeFlipped(x, i))             ssc++;
  }
  out[0] = mav / WIN;
  out[1] = sqrtf(sq / WIN);
  out[2] = zc;
  out[3] = wl / WIN;
  out[4] = ssc;
}
Decide and move · core 1
void controlTask(void*) {
  for (;;) {
    xSemaphoreTake(windowReady, portMAX_DELAY);

    extractFeatures(ring[0], &feat[0]);
    extractFeatures(ring[1], &feat[5]);
    normalise(feat, mu, sigma, 10);         // z-score, constants from training

    for (int i = 0; i < 10; i++)
      input->data.int8[i] = quantise(feat[i], in_scale, in_zp);

    if (interpreter->Invoke() != kTfLiteOk) continue;

    uint8_t cls  = argmax(output->data.int8, N_CLASS);
    float   conf = softmaxTop(output->data.int8, N_CLASS);

    pushVote(cls);                             // 3-frame majority vote
    if (voteStable() && conf > CONF_MIN) {
      grip = majority();
      applyGrip(GRIP_TABLE[grip], forceTarget); // ramps PWM, stops on FSR
    }
  }
}

GRIP_TABLE holds six joint angles per class. applyGrip ramps each servo at 240°/s rather than stepping, which stops the hand snapping and halves the current spike.

FOR CONTEXT

A commercial myoelectric hand

Clinical multi-articulating hands manage 8–14 grips, 60–100 N and 8-hour wear, with pattern recognition trained by a prosthetist. They also cost roughly a thousand times this build.

Typical clinical cost₹8–40 lakh
WHAT THIS PROVES

The control chain, end to end

The point of H1 is not to match a clinical device. It is to show that the full chain — electrode, amplifier, embedded DSP, trained classifier, actuation, force feedback — can be built and measured by one student with parts off a shelf.

Build time14 weeks
WHAT IS NEXT

Proportional, not just discrete

Right now the hand picks one of seven grips. The more useful version reads how hard you are trying and closes proportionally, which needs a regression head alongside the classifier.

07 / Nerve link

How this gets to a real nerve interface

The project goal is a hand driven by the nerves that used to drive the real one. Surface EMG is the honest first step toward that, not a substitute for it — here is the actual ladder, and where H1 sits on it.

Level 1
Where H1 is

Surface EMG over remaining muscle

Electrodes on the skin read whatever forearm muscle is still intact and voluntarily controlled. Non-invasive, instantly reversible, and limited by how few distinct patterns the skin can resolve — which is why seven grips is near the practical ceiling for two channels.

Level 2
Phase 2 · buildable

High-density electrode array

Replace two pads with a 16- to 32-contact band around the forearm. The same features over many channels separate intents that two channels blur together, pinch versus tripod among them. Still non-invasive; the cost is a bigger model and a real ADC front end instead of the ESP32's.

Level 3
Clinical · surgical

Targeted muscle reinnervation

A surgeon reroutes the severed median and ulnar nerves into spare muscle in the residual limb. Those muscles then contract when the person intends to move a finger, and ordinary EMG electrodes can read a nerve-level intent. This is the step that turns "muscle control" into "nerve control" without putting electronics inside a nerve.

Level 4
Research

Regenerative peripheral nerve interfaces

Small muscle grafts wrapped around individual nerve fascicles, each with its own implanted bipolar electrode. Published work reports stable finger-level signals over years, and it is the most plausible route to per-finger proportional control plus sensory feedback by stimulating the same nerve.

Level 5
Research

Direct intraneural electrodes

Thin-film or needle arrays inside the nerve itself, reading and writing individual fascicles. Highest bandwidth, hardest problem: the body encapsulates foreign bodies, so long-term signal stability and surgical risk are unsolved rather than engineering details.

Scope statement for the viva

Levels 3 to 5 need a surgical team, ethics approval and a patient. Nothing on this page claims those were done. H1 is a Level 1 device built so that the control software, feature pipeline and actuation would transfer upward with a change of signal source rather than a rewrite.

WHAT TRANSFERS UPWARD

The software, almost unchanged

  • Windowing and feature extraction are channel-count agnostic
  • The classifier only needs retraining, not redesign
  • Voting, ramping and FSR force limiting are signal-source independent
  • Grip table and kinematics stay identical
WHAT HAS TO CHANGE

The front end and the arena

  • ESP32's SAR ADC is not good enough past ~4 channels
  • 16+ channels wants an ADS1299-class AFE
  • Implanted signals need isolation and a certified power path
  • Sensory feedback needs a current-controlled stimulator, not a buzzer
